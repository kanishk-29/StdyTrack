Study Tracker — a project journal I. The Story
The story behind it

Some people are wired to organize their time.

College classes. A personal reading list of the books actually meant to grow you. A research thread followed on your own. A team project with its own deadlines, riding on other people too. Caring about organizing time was never the problem — juggling four different lives that all needed it, was.

"Staying organized shouldn't be its own project."
SCROLL
The problem

Four commitments, one calendar, and no idea which one needs you next.

Between college coursework, self-study, and a team project, the actual studying was never the hard part — knowing which one deserved the next hour was. A subject would quietly go untouched for a week while another got over-studied, simply because there was no honest view of where time was actually going.

And the notes told the same story. A Notepad file for one subject, a different folder for the personal research, another scattered set of pages for the team project — "staying organized" had quietly become its own mess to manage, on top of the actual work.

Juggling it alone

  • College, personal study, and team work all competing for the same hours, with no shared view
  • Multiple Notepad files and folders per commitment — the "organizing" becomes its own mess
  • No sense of which subject has been quietly neglected until it's urgent
  • Realizing the night before an exam that there was never a real plan
  • No overview of where the hours actually went across everything

With one system

  • Every commitment — college, personal, team — structured the same way, side by side
  • One searchable home for notes, replacing scattered files and folders
  • Neglected subjects surface in the data before they become a problem
  • Daily goals set the night before an exam, not guessed at that morning
  • A real analytics overview of exactly where every hour went
The moment notes need their own filing system just to be found again, the system has already failed you.
The solution

One place for every kind of studying — with a companion along for it.

Study Tracker isn't built for one kind of student. It's built for anyone holding college classes, a personal growth list, and a group project at the same time — and it answers the actual question: where should today's attention go, and where did it already go?

Subjects → Units → Lectures, for anything

College courses, a personal reading or research list, a team project's modules — the same clean structure holds all of it, so nothing needs its own separate system.

One searchable home for notes

Replaces the scattered Notepad files and folders with rich-text notes per lecture — searchable across all of them at once.

Daily goals, set the night before

Plan tomorrow's priorities before the exam morning arrives — so nothing is left to guessing under pressure.

Analytics that show where time actually went

A real overview across every subject and project, so attention is a decision — not an accident noticed too late.

Rei — a companion, not just a tracker

Reacts to the actual pattern of your days: present for the streaks, honest when a subject's been quietly ignored. Company for the parts of studying that are usually done alone.

Rei is what makes checking in feel like less of a chore — a small, familiar presence that's there whether the day's log is a proud one or an honest zero.

The parts nobody sees

Decisions that only matter the moment something goes wrong.

Anyone can list features. The part that took real thought was the edge cases underneath them — the moments where a lesser build would quietly lose data, drift out of sync, or just break.

Timezone-correct "today"

Each day is computed from a noon-anchored date in the user's selected zone — not the device clock — across 24 presets, so the calendar never flips a day early or late at a boundary.

Offline mode that doesn't rot

The service worker strips query strings like ?v=56 before matching cached files, so shipping a new version never silently breaks the offline shell.

Deterministic conflict resolution

Open the same account on two devices and the app doesn't try to merge. It compares an updatedAt timestamp and takes the newer copy — every time, predictably.

A mascot with restraint

Rei's reactions are pooled and cooldown-gated per context, with a hidden rapport score, so the same line never fires twice in a row.

Cost-aware cloud writes

Pushes are throttled to once per 15 seconds per user, with a trailing write guaranteed — so a free-tier backend survives a whole semester of real use.

Pacing, computed — not guessed

Given an exam date, the app works out the required pace across remaining units and lectures, not just a countdown to a number.

A timer that survives a reload

The global session timer's minutes live in their own storage key, apart from the main document — a refresh can't corrupt a session mid-count.

Storage that adapts to where it runs

The app auto-detects a host-provided storage API first, falls back to IndexedDB, then localStorage — unmodified, wherever it runs.

Under the hood

Eighteen functional modules, specced like production software.

This isn't three ideas duct-taped together. It's built and documented against an actual Software Requirements Specification — IEEE 830-1998, adapted for a solo build — with every module traced back to real source files.
